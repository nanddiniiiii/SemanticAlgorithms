## Focused fixes made in this audit

- `SharedCode/reproduction/accounting.py` now requires measured primary complex uses, actual serialized index payload bits, actual coded bits, and modulation before reporting a total NTSCC+ CBR. It rounds up partial modulation symbols and counts padded-image transmission in the numerator while retaining original RGB pixels in the denominator. No coding rate is inferred.
- `SharedCode/reproduction/profiling.py` refuses a training FLOP receipt without a real backward and applied optimizer step. It lists unsupported operations and marks those totals as partial supported-operator counts. It does not manufacture backward FLOPs from a forward multiplier.
- `SharedCode/reproduction/matched_evaluation.py` gained a native full-image path with explicit model alignment; the existing tiled path remains a separate protocol. Both paths now reject malformed optional bit/FLOP counts. Model callbacks still require runtime validation and cannot be inferred from these helpers.
- CPU checks: `python -m pytest SharedCode/reproduction/tests/test_accounting_and_geometry.py -q -rs` gave **2 passed, 1 skipped**. The skipped native-image metric check needs the unavailable `pytorch_msssim` package in this interpreter. No model weights or channels were exercised by these tests.
