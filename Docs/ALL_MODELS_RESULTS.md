# All-model implementation, checkpoint and results inventory

Snapshot: 26 October 2026. Local receipts and files were checked for this inventory.
This is a progress table, not a performance ranking: datasets, rates, channel
settings and metric protocols differ. A model folder or train entry point alone
does not establish a working implementation. No complete paper training
reproduction has been established in this execution.

## All models

### Current training selection and input policy (26 October)

Recommended target roster: DeepJSCC, ADJSCC, SwinJSCC, JCM, masked SQ-GAN,
Shared Semantic-Aware Codebook, DeepJSCC-Q, MDJCM, VQ-DeepISC, AMP-SC.
Only accountB via WSL is authorized for new training, with DataParallel validated
per method. MambaJSCC, NTSCC and diffusion methods are excluded from the new
training queue, while old results stay available. These are ten study targets;
this is not a statement that ten native trainers are integrated.

Author input contracts stay intact except the explicitly approved larger-image,
reconstruction-only JCM variant (kept separate from native CIFAR10 JCM). SQ-GAN
custom inputs retain RGB plus paired maps generated by a pinned frozen
Cityscapes segmenter; Shared Codebook construction retains labels supplied by
the frozen10-class classifier for custom images. Both are pseudo-label
adaptations, not original-paper supervision. Native ground-truth-label branches
remain separate. See STAGE_ONE_BASELINES.md for the canonical comparison plan.

AMP-SC source is now downloaded and hash-verified at author commit
063d8098633cf31acd236982b8510d969d225d7c. It implements scalar-quantized digital
bits, bit flips and mask-attack alternating training, but expects a pretrained
feature codec whose author Baidu link has not been retrieved. It is not runnable
training by default, and no AMP-SC weights or result are claimed.

VQ-DeepISC remains a requested paper-reimplementation/release-verification
target. No verified author release was found in this bounded check. MDJCM's
default release disables digital modulation; its digital/staged training must
be validated. DeepJSCC-Q's previously confirmed quantizer faults remain gates.

Two useful additional digital references are BPG+LDPC/QAM and a learned
entropy-coded RGB codec+LDPC/QAM. They are actual bitstream reference systems,
not extra semantic-paper algorithms or measured results yet.

## Measured results with protocol

New native Swin receipts: `Docs/validation/swin_{fixed_c32,sa_ra}_gpu_metrics.json`
and corresponding `profile_{full,encoder,decoder}.json`. Both Kodak24 variants
completed on account B version2. Full fixed/adaptive T4 FP32 batch1 latency p50:
260.84/274.57ms at512x768; partial profiler counts413.428/428.977GFLOPs.
These are measured forwards, not complete arithmetic totals. See
[the Stage1 report](STAGE_ONE_REPORT.md) for the consolidated evidence and limits.

JCM's native SSIM uses its source convention (data_range=1 with normalized
[-1,1] inputs); it must not be treated as interchangeable with standard RGB SSIM.
SQ-GAN's auto-range PSNR formula also gives 21.001077 dB, but the original
unpinned torchmetrics version has not been reproduced. LPIPS, MS-SSIM and
InternImage mIoU were not measured in this SQ-GAN run. These are lossy image
reconstruction experiments, not evidence of exact/lossless delivery.

## Current work and execution order

The two latest checked Kaggle jobs are finished: SQ-GAN completed, Mamba failed.
No long training job was launched by those submissions. We have not trained
every registered model for 150 epochs, and we have not yet demonstrated a new
method outperforming the papers.

1. Native Swin checkpoint evaluation is complete. Investigate the adaptive
   checkpoint's low quality; preserve the excluded retained run separately.
2. Evaluate ADJSCC and verify DeepJSCC's legacy channel/rate operating point.
3. Complete inference timing, memory and supported FLOPs reports for runnable
   models, preserving unsupported-operation and diffusion-gradient limitations.
4. Validate Shared Codebook native data/construction and SQ-GAN's staged native
   training before spending GPU quota on full runs.
5. Repair Mamba compatibility and integrate DiffJSCC as separate bounded pilots;
   retain DeepJSCC-Q/MDJCM as pending until their specific blockers are resolved.
6. Build matched baseline comparisons before testing improvements. First compare
   rate/quality curves under the same data and channel; then evaluate novelty.

The immediate goal is a defensible collection of verified baselines across
families, followed by matched improvements. A registry entry, downloaded
checkpoint, CPU test and completed quality benchmark are distinct milestones.
