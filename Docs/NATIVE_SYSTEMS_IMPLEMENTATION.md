## SSC recovery, 29 October 2026

Person2 v2 failed only SSC's two-rank pilot: the pinned author ssc/archs/modules.py imports timm.layers, while our environment incorrectly pinned timm0.4.12. This was our dependency mismatch, not a demonstrated algorithm failure. SSC now requests timm1.0.29 and executes the exact required API import immediately after dependency installation. Other models retain their existing dependency pins. No architecture, loss, input dimensions, quantizer or channel changes are made by this fix. The local pre-existing timm1.0.28 passed real CPU optimizer/reload checks; exact1.0.29 follow-up is run separately.

The launcher now accepts --models ssc to submit only the failed assigned model while retaining the canonical four-model notebook. It does not retrain the three successful models. Source/version/run identities remain separate and previous outputs must be retrieved before retry.

Additional Person2 candidates: native JCM is the strongest ready reference for fixed-alphabet coding/modulation versus MDJCM; its native CIFAR10/task setting stays separate from common high-resolution comparisons. AMP-SC adds alternating phase training and mask attacks, but the pinned trainer requires results/DSC_best_model_pretrained.pth; that prerequisite and complete phase budget must be verified before any launch. DeepJSCC-Q remains important but its third-party candidate has documented quantizer/fidelity problems (DEEPJSCC_Q_REPRODUCTION_AUDIT.md); it is not ready for a paper-faithful quick run. No new candidate training is claimed.
